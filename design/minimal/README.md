# Архив минимальных вариантов

Актуальная основная версия: [ROBOT_BASELINE.md](../../ROBOT_BASELINE.md), около 40 см, локальная модель и приводы с обратной связью. Эти минимальные варианты сохранены для сравнения и не являются текущим списком полной закупки.

Единый список покупок: [ROBOT_MINIMAL.md](../../ROBOT_MINIMAL.md). В нём конкретные товары, ссылки, цены и суммарная смета 16 392 ₽ с резервом 3 000 ₽; при альтернативной цене платы — 18 680 ₽. Остальные файлы в этой папке содержат подробное обоснование архитектуры.

Первая версия ограничена ходьбой, поворотной головой, камерой и Wi-Fi. Основной документ: [minimal-version.md](minimal-version.md).

Полная закупочная подборка procurement/ сохранена как история и источник деталей, но не является минимальным списком. Изменение архитектуры не подтверждает новыйCAD/прошивку/походку: их ещё предстоит разработать и проверить.
